> 奖项：芯片应用赛道全国总决赛 · 一等奖

> 团队：伏安超充 · 厦门大学嘉庚学院

## 📖 作品简介

伏安超充基于RK2206主控、WS63双终端、昇腾边缘网关、云服务器与鸿蒙应用五层协同构建，模块多为自研PCB，实现光伏发电、储能与充电全链路智能管理。桩端运行OpenHarmony轻量系统，支持双枪控制与全流程管理，实时采集电压、电流、SOC、枪温、SOH等参数，具备过温保护、火灾断电、拔枪检测等安全机制；WS63终端实现车桩协同与光伏追光；昇腾网关完成协议转换与数据上云；云端基于FastAPI提供订单、结算、监控等服务；鸿蒙APP适配实况窗、桌面卡片等特性。作品形成“端侧采集—边缘汇聚—云端管理—移动交互”完整闭环。

## 🧠 核心功能

- 创新魔改typec，一根线实现插入检测、与小车通信

- 创新结合光伏、储能与UPS，最大化挖掘融合三者优点

- 采用累计电荷量与电池实际提升SOC比值算法，低成本实现健康度检测

- 方案全面且高度可用，可接入实际充电场景

- 采用美观、简介的APP设计，用户上手低门槛

## 🏗️ 系统架构

系统以RK2206为边缘计算核心，连接摄像头、充电模块、触摸屏、等部件设备；详细架构与硬件设计见 `docs/volt.pdf`。
